## 真实 Windows 桌面（建议先在虚拟机）

设置一个短期测试安排：承诺中心为几分钟后、随机 1 分钟、首次提醒晚于随机窗口上界、限制再晚几分钟、解除为次日合法时间。**提前确认README 中的紧急暂停长命令可用**，测试结束使用管理员恢复，不必等一整晚。

- [ ] 第一次安装后未启用计划；UAC 使用不同管理员账户时，受约束 SID 仍为原用户。
- [ ] 白天可以保存设置；承诺开始没有主动弹窗泄露时刻。
- [ ] 在首次提醒出现后停用计划、调整时间、清空当前星期（保留其他星期），今晚仍执行旧快照。
- [ ] 承诺前后反复重启 App/服务，具体随机时刻不重抽。
- [ ] 正常提醒、五分钟提醒、最后一分钟多屏倒计时；关闭提醒不能取消限制。
- [ ] 托盘“预览睡前提醒”持续显示且可以关闭，不修改计划，不锁屏。
- [ ] 单屏、双屏、负坐标副屏、100%/150% 混合缩放；任务栏不会让倒计时窗口尺寸失真。
- [ ] 到点进入 Windows 原生锁屏；再次解锁后恢复限制，后台文件和程序未被结束。
- [ ] 等待到解除时间后可以正常解锁；不会自动登录。
- [ ] 暂停/休眠后唤醒，仍在限制期会执行；已经过期不补锁。
- [ ] 限制期重启电脑并登录，旧快照继续；其他 Windows 用户不受限制。
- [ ] 快速用户切换与 RDP 连接/断开之后，目标账号的会话仍受约束。
- [ ] 结束托盘进程后服务拉起；连续故障不会无限高频启动。
- [ ] 临时禁用任务管理器开启时，承诺开始后阻止新开任务管理器。
- [ ] 任务管理器在承诺前已经打开的行为单独记录；不保证能关闭既有实例。
- [ ] 真实策略的初始“不存在”和“DWORD 0”两种情形，结束后分别恢复原状。
- [ ] 直接结束服务进程后，SCM 恢复；阻止服务恢复后，独立任务在心跳过期后恢复策略。
- [ ] 用户注销导致 hive 卸载时，恢复保留记录，用户下次登录后可重试。
- [ ] 使用完整长参数执行紧急暂停，停止重复锁屏并恢复策略。
- [ ] 重新启用恢复旧计划；卸载删除服务、任务、快捷方式和文件，不留下策略。
- [ ] 家庭版任务管理器策略支持情况、域/MDM 管理设备拒绝策略的提示，分别记录具体 Windows 版本。

## 单 EXE 与周期休息交互验收

- [ ] 未安装运行时的干净系统提示安装 .NET 10 Desktop Runtime；安装后仅凭一个 EXE 可启动。
- [ ] 双击 EXE 显示安装/重新启用/卸载及配置，没有暂停按钮，无 CMD/PowerShell 窗口。
- [ ] 点击安装并完成 UAC，开始菜单入口正常；关闭窗口后托盘与后台仍运行。
- [ ] 无承诺时从已安装应用或下载的 EXE 发起卸载，成功清理安装目录；失败时保留可重试的恢复记录。
- [ ] 休息配置 a=6、b=1、c=1、d=2：累计 4 分钟承诺、5 分钟提醒、6—7 分钟限制。
- [ ] 承诺前手动锁屏/注销/休眠不累计；只有已解锁目标会话累计。
- [ ] 休息承诺后修改 a/b/c/d、停用、重启程序，本轮固定时间不改变。
- [ ] 休息承诺后休眠，唤醒时仍在本轮则限制，已过期则重新累计。
- [ ] 休息结束后重新累计；夜间限制清零休息，次日正常开始新周期。
- [ ] 两种提醒重叠显示最近锁屏；两种策略租约重叠不会提前恢复任务管理器。

## 承诺期卸载保护

- [ ] 睡眠承诺、睡眠提醒、睡眠限制、休息承诺、休息提醒、休息限制期间，卸载均变灰。
- [ ] 解除最后一个承诺后卸载重新可用；服务失联时暂不可用。
- [ ] 从 Windows 卸载入口或直接调用普通维护入口，承诺期均被拒绝，原服务继续执行。
- [ ] 旧 `--recovery` 和无长参数的 Repair 不执行暂停；开始菜单没有恢复快捷方式。
- [ ] 完整长参数可以在管理员授权后紧急暂停或强制卸载；暂停后重新启用继续有效承诺。

- [ ] 旧版数据首次打开后工作间隔正确显示分钟；保存后使用 WorkMinutes。
- [ ] 覆盖提示选择“否”不修改安装；选择“是”保留配置、冻结安排和暂停状态。
- [ ] 仅剩数据时可以覆盖修复，原进度不清零。
- [ ] 下载新版双击后从新版管理窗口执行覆盖，随后运行安装目录的新程序。
