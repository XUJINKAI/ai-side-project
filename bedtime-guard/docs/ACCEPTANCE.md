## 自动化

- 核心测试：默认关闭、随机窗口两端、首次提醒前冻结、精确边界保存、修改只影响以后、重启不重抽、跨午夜、星期、时钟回拨、DST、持久化损坏。
- Windows 策略测试：仅在临时测试路径操作，验证原值不存在/为 0、外部改值、崩溃准备记录、到期、心跳过期、拒绝接管既有策略、拒绝管理设备、损坏日志保留。
- Windows 安装烟雾测试：使用真实服务/管道，日程始终 Disabled；验证安装、恢复、重新启用、卸载，不调用真实锁屏或禁用任务管理器。

## 真实 Windows 桌面（建议先在虚拟机）

设置一个短期测试安排：承诺中心为几分钟后、随机 1 分钟、首次提醒晚于随机窗口上界、限制再晚几分钟、解除为次日合法时间。**提前打开另一个管理员终端并确认恢复脚本路径**，测试结束使用管理员恢复，不必等一整晚。

- [ ] 第一次安装后未启用计划；UAC 使用不同管理员账户时，受约束 SID 仍为原用户。
- [ ] 白天可以保存设置；承诺开始没有主动弹窗泄露时刻。
- [ ] 在首次提醒出现后停用计划、调整时间、清空当前星期（保留其他星期），今晚仍执行旧快照。
- [ ] 承诺前后反复重启 App/服务，具体随机时刻不重抽。
- [ ] 正常提醒、五分钟提醒、最后一分钟多屏倒计时；关闭提醒不能取消限制。
- [ ] 托盘“预览睡前提醒”持续显示且可以关闭，不修改计划，不锁屏。
- [ ] 单屏、双屏、负坐标副屏、100%/150% 混合缩放；任务栏不会让倒计时窗口尺寸失真。
- [ ] 到点进入 Windows 原生锁屏；再次解锁后恢复限制，后台文件和程序未被结束。
- [ ] 等待到解除时间后可以正常解锁；不会自动登录。
- [ ] 暂停/休眠后唤醒，仍在限制期会执行；已经过期不补锁。
- [ ] 限制期重启电脑并登录，旧快照继续；其他 Windows 用户不受限制。
- [ ] 快速用户切换与 RDP 连接/断开之后，目标账号的会话仍受约束。
- [ ] 结束托盘进程后服务拉起；连续故障不会无限高频启动。
- [ ] 临时禁用任务管理器开启时，承诺开始后阻止新开任务管理器。
- [ ] 任务管理器在承诺前已经打开的行为单独记录；不保证能关闭既有实例。
- [ ] 真实策略的初始“不存在”和“DWORD 0”两种情形，结束后分别恢复原状。
- [ ] 直接结束服务进程后，SCM 恢复；阻止服务恢复后，独立任务在心跳过期后恢复策略。
- [ ] 用户注销导致 hive 卸载时，恢复保留记录，用户下次登录后可重试。
- [ ] 从开始菜单/另一管理员会话执行恢复，停止重复锁屏并恢复策略。
- [ ] 重新启用恢复旧计划；卸载删除服务、任务、快捷方式和文件，不留下策略。
- [ ] 家庭版任务管理器策略支持情况、域/MDM 管理设备拒绝策略的提示，分别记录具体 Windows 版本。
