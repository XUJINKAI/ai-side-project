# Bedtime Guard

Windows 常驻睡眠提醒与适度强制锁屏工具。C# / .NET 10 / WPF，后台 Windows 服务负责计划、状态和界面进程恢复。

## 默认安排

| 阶段 | 默认时间 | 行为 |
| --- | --- | --- |
| 白天 | 承诺期之前 | 可修改或停用计划 |
| 随机承诺开始 | 20:00 ± 30 分钟 | 每晚独立抽取一次；悄悄冻结当晚计划，不提前提醒 |
| 首次提醒 | 22:00 | 此时已经不能取消或推迟当晚计划 |
| 收尾提醒 | 22:55、22:59 | 弹窗；最后一分钟覆盖各个显示器显示倒计时 |
| 限制期 | 23:00—次日 06:00 | 调用 Windows 原生锁屏；解锁后再次限制 |
| 解除 | 次日 06:00 | 停止重复锁屏、恢复本工具修改的任务管理器策略 |

**不提供延期或“今晚跳过”。** 安装后计划默认未启用，先检查设置，再勾选启用并保存。

随机承诺时间不在界面/API 中公布；同一晚重复保存、重启程序、重启服务不会重新抽签。设置界面仍可以保存后续安排，但服务保留已冻结的当晚快照，即使把后续计划停用，当晚仍执行。星期归属于开始承诺的晚上，例如周五包括周六凌晨。

## 安装与使用

目标：Windows 11 x64 / ARM64；任务管理器策略建议在个人、未受域或 MDM 管理的 Windows 专业版机器使用。家庭版是否执行此策略需要实机确认；原生锁屏不依赖该增强项。

1. 下载或构建 `BedtimeGuard-win-x64.zip`，解压。
2. 双击根目录 `Install.cmd`。安装会请求管理员权限，记录提权前的用户 SID。
3. 从托盘或开始菜单打开 **Bedtime Guard**，检查星期、时区和时间，勾选启用并保存。
4. 需要时勾选“承诺期开始后临时禁用任务管理器”。这是独立可选项，默认关闭。

发布包自带 .NET 运行时，不需要额外安装 .NET，不使用 MSIX。默认安装到 `C:\Program Files\BedtimeGuard`，数据保存到 `C:\ProgramData\BedtimeGuard`。服务开机自动启动，并在选定账号的交互会话中启动托盘程序。关闭设置窗口继续常驻。

可选择 Program Files 下的新目录：

```powershell
.\scripts\Install.ps1 -InstallDir 'C:\Program Files\MyTools\BedtimeGuard'
```

如果手动从已经提权的其他管理员账户安装，请使用 `-UserSid` 明确指定受约束账户。服务二进制所在目录必须受管理员保护，因此不支持把 SYSTEM 服务直接运行在下载目录或其他普通用户可写目录。安装器拒绝覆盖已有安装/状态，也拒绝路径中的符号链接或目录联接。

## 恢复、重新启用与卸载

开始菜单提供以下入口，均需管理员权限：

| 入口 | 等效脚本 | 行为 |
| --- | --- | --- |
| Bedtime Guard - Repair（恢复） | `scripts\Repair.ps1` | 写入暂停标记、停止服务、还原任务管理器策略 |
| Bedtime Guard - Resume（重新启用） | `scripts\Resume.ps1` | 清除暂停标记，启动服务，恢复保存的计划 |
| Bedtime Guard - Uninstall（卸载） | `scripts\Uninstall.ps1` | 先恢复策略，再删除服务、恢复任务、进程、快捷方式和文件 |

恢复入口始终保留，没有冷却时间、答题或延期额度。重新启用时，如果原来的当晚快照仍未到解除时间，会继续执行它。

恢复脚本也可以从其他管理员会话运行。若受约束用户已经注销、注册表配置单元尚未加载，策略恢复会保留日志并明确报错；让该用户登录后再次恢复。不要在此情况下直接删除安装目录。卸载在恢复未完成时会中止，不会删除唯一的恢复记录。

`Uninstall.ps1 -KeepData` 可保留受保护的数据供排查；要重新安装，应先由管理员归档并移走保留的数据目录，安装器不会静默重置旧状态。升级采用“卸载旧版、安装新版”的显式流程。

配置损坏时，服务拒绝启动，不会偷偷重建当晚状态。先运行恢复，再由管理员备份数据并重新安装。只删除 `paused` 不会修复损坏的 JSON。

## 约束强度与边界

- 服务是计划唯一裁判。界面进程被结束后通常在下一次 5 秒检查时恢复；同一会话 5 分钟内最多启动 3 次，避免崩溃风暴。
- 服务异常终止由 SCM 最多重启两次；管理员主动停止服务不作为崩溃处理。
- Windows 锁屏不修改账户密码，不注销，不结束其他程序，不关闭未保存文件。后台下载、编译、音视频可能继续运行。
- 能输入密码解锁，但在服务和会话程序正常工作时会再次锁定，通常有短暂桌面可用间隙。管理员仍可停止/卸载；不防安全模式、替换系统文件或主动修改系统时钟。
- 不拦截 Ctrl+Alt+Del，不注入系统进程，不安装驱动，不禁用命令行，不创建互相无限拉起的进程。
- 任务管理器策略仅对选定 SID 生效；不接管原本已经启用的限制。若检测到域或 MDM enrollment，则拒绝修改。检测是保守检查，并非所有企业管理机制的完整识别。
- 独立任务每分钟、开机及登录时检查策略恢复记录。到期或服务心跳超过 2 分钟未刷新时尝试恢复；任务调度延迟、用户注册表尚未加载时可能推迟到下一次成功执行。
- 服务失联时界面不使用过期状态无限锁屏。故障时优先恢复电脑可操作性，界面显示服务未连接。
- 时区随计划保存；已经冻结的当晚使用固定时间点。跨午夜、睡眠恢复、错过开始时间后登录均重新计算，不补执行已经结束的夜晚。
- 第一版的日程形态是“同一天承诺、提醒、开始限制，次日早晨解除”，不支持轮班的任意多段计划。

## 构建与测试

开发需要 .NET 10 SDK。构建结果统一在 `out/`，不提交二进制。

```powershell
# 运行核心测试，可在 Linux/macOS/Windows 运行
dotnet run --project tests/BedtimeGuard.Tests -c Release

# 在 Windows 运行策略恢复测试：使用独立测试注册表路径，不修改真实任务管理器策略
dotnet run --project tests/BedtimeGuard.Windows.Tests -c Release

# 构建客户端、服务和自带运行时的安装 ZIP；自动先运行测试
.\build.ps1
.\build.ps1 -Runtime win-arm64
```

Windows 构建流水线会生成 ZIP 和 SHA-256 文件，并在一次性 runner 上执行禁用计划状态下的安装、真实 Named Pipe 通信、恢复、重新启用和卸载测试。完整人工验收见 [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md)。

仅用于一次性 Windows 测试机器，管理员执行安装烟雾测试：

```powershell
.\scripts\Smoke-Test.ps1 -Bundle "$PWD\out\BedtimeGuard-win-x64"
```

不要把构建成功当成已验证交互锁屏。真实桌面的锁屏/解锁、多屏与缩放、任务管理器策略及休眠唤醒需要人工验收。

## 代码结构

- `src/BedtimeGuard.Core`：日程校验、每晚随机样本、冻结快照、跨日状态、JSON 原子保存。
- `src/BedtimeGuard.Windows`：受保护路径、策略恢复日志、会话进程启动、IPC 帧协议。
- `src/BedtimeGuard.Service`：Windows 服务、权威状态、命令验证、恢复命令、有限进程恢复。
- `src/BedtimeGuard.App`：WPF 设置、托盘、提醒、多屏倒计时、交互会话锁屏。
- `tests`：时间规则测试，以及隔离注册表路径的 Windows 策略事务测试。
- `scripts`：安装、恢复、重新启用、卸载与烟雾测试。

设计约定见 [docs/DESIGN.md](docs/DESIGN.md)。
