## 自动化

- 核心测试：默认关闭、随机窗口两端、首次提醒前冻结、精确边界保存、修改只影响以后、重启不重抽、跨午夜、星期、时钟回拨、DST、持久化损坏。
- Windows 策略测试：仅在临时测试路径操作，验证原值不存在/为 0、外部改值、崩溃准备记录、到期、心跳过期、拒绝接管既有策略、拒绝管理设备、损坏日志保留。
- Windows 集成测试：单 EXE 实际窗口启动，原生安装、真实服务/管道、休息承诺后禁止取消、恢复、重新启用与卸载；不进入实际锁屏期，不禁用真实任务管理器。

## 真实 Windows 桌面（建议先在虚拟机）

设置一个短期测试安排：承诺中心为几分钟后、随机 1 分钟、首次提醒晚于随机窗口上界、限制再晚几分钟、解除为次日合法时间。**提前确认README 中的紧急暂停长命令可用**，测试结束使用管理员恢复，不必等一整晚。

- [ ] 第一次安装后未启用计划；UAC 使用不同管理员账户时，受约束 SID 仍为原用户。
- [ ] 白天可以保存设置；承诺开始没有主动弹窗泄露时刻。
- [ ] 在首次提醒出现后停用计划、调整时间、清空当前星期（保留其他星期），今晚仍执行旧快照。
- [ ] 承诺前后反复重启 App/服务，具体随机时刻不重抽。
- [ ] 正常提醒、五分钟提醒、最后一分钟提醒（分钟显示）；关闭提醒不能取消限制。
- [ ] 左键单击托盘始终显示状态页；悬停显示距休息分钟数和工作暂停提示；右键有 5/10/30/60/120 分钟、直到明天和手动遮罩。
- [ ] 单屏、双屏、负坐标副屏、100%/150% 混合缩放；任务栏不会让倒计时窗口尺寸失真。
- [ ] 勾选锁屏时，到点进入 Windows 原生锁屏；再次解锁后恢复限制，后台文件和程序未被结束。
- [ ] 等待到解除时间后可以正常解锁；不会自动登录。
- [ ] 暂停/休眠后唤醒，仍在限制期会执行；已经过期不补锁。
- [ ] 限制期重启电脑并登录，旧快照继续；其他 Windows 用户不受限制。
- [ ] 快速用户切换与 RDP 连接/断开之后，目标账号的会话仍受约束。
- [ ] 结束托盘进程后服务拉起；连续故障不会无限高频启动。
- [ ] 临时禁用任务管理器开启时，承诺开始后阻止新开任务管理器。
- [ ] 任务管理器在承诺前已经打开的行为单独记录；不保证能关闭既有实例。
- [ ] 真实策略的初始“不存在”和“DWORD 0”两种情形，结束后分别恢复原状。
- [ ] 直接结束服务进程后，SCM 恢复；阻止服务恢复后，独立任务在心跳过期后恢复策略。
- [ ] 用户注销导致 hive 卸载时，恢复保留记录，用户下次登录后可重试。
- [ ] 使用完整长参数执行紧急暂停，停止重复锁屏并恢复策略。
- [ ] 重新启用恢复旧计划；卸载删除服务、任务、快捷方式和文件，不留下策略。
- [ ] 家庭版任务管理器策略支持情况、域/MDM 管理设备拒绝策略的提示，分别记录具体 Windows 版本。

## 单 EXE 与周期休息交互验收

- [ ] 未安装运行时的干净系统提示安装 .NET 10 Desktop Runtime；安装后仅凭一个 EXE 可启动。
- [ ] 双击 EXE 显示安装/重新启用/卸载及配置，没有暂停按钮，无 CMD/PowerShell 窗口。
- [ ] 点击安装并完成 UAC，开始菜单入口正常；关闭窗口后托盘与后台仍运行。
- [ ] 无承诺时从已安装应用或下载的 EXE 发起卸载，成功清理安装目录；失败时保留可重试的恢复记录。
- [ ] 休息配置 a=13、b=1、c=1、d=2：累计 11 分钟承诺、12 分钟提醒、13—14 分钟限制。
- [ ] 承诺前手动锁屏/注销/休眠不累计；只有已解锁且符合键鼠活动条件的目标会话累计。
- [ ] 休息承诺后修改 a/b/c/d、停用、重启程序，本轮固定时间不改变。
- [ ] 休息承诺后休眠，唤醒时仍在本轮则限制，已过期则重新累计。
- [ ] 休息结束后重新累计；夜间限制清零休息，次日正常开始新周期。
- [ ] 两种提醒重叠显示最近锁屏；两种策略租约重叠不会提前恢复任务管理器。

## 承诺期卸载保护

- [ ] 睡眠承诺、睡眠提醒、睡眠限制、休息承诺、休息提醒、休息限制期间，卸载均变灰。
- [ ] 解除最后一个承诺后卸载重新可用；服务失联时暂不可用。
- [ ] 从 Windows 卸载入口或直接调用普通维护入口，承诺期均被拒绝，原服务继续执行。
- [ ] `--recovery` 和无长参数的 Repair 不执行暂停；开始菜单没有恢复快捷方式。
- [ ] 完整长参数可以在管理员授权后紧急暂停或强制卸载；暂停后重新启用继续有效承诺。

- [ ] 覆盖提示选择“否”不修改安装；选择“是”时配置和有效承诺保留。
- [ ] 仅剩数据时可以覆盖修复，原进度不清零。
- [ ] 下载新版双击后从新版管理窗口执行覆盖，随后运行安装目录的新程序。

- [ ] 小数分钟与 a−d≤10 的配置均被拒绝；a−d=11 可以保存。
- [ ] 休息长于工作间隔时仍只运行一轮，休息结束后重新累计。

## Force Break 新交互

- [ ] 四页在常用分辨率下不需要浏览整个长面板；切页不丢未保存配置，状态刷新不覆盖编辑。
- [ ] 新安装默认时间为 20:00±30、21:30、22:30、06:00；工作 50、休息/提醒/承诺各 10 分钟。
- [ ] 键鼠检测、任务管理器策略、遮罩默认勾选，锁屏默认不勾选；计划需主动启用。
- [ ] 屏幕常亮但超过 1 分钟无键鼠操作，工作进度暂停；随后键盘和鼠标分别能恢复累计。
- [ ] 行为页修改空闲阈值有效；关闭检测后解锁状态继续累计；输入检测失联不会继续盲目累计。
- [ ] 承诺后离开电脑不推迟休息；更改遮罩或锁屏开关不改变本轮。
- [ ] 手动休息在自动周期关闭时也生效；有效承诺期间不能用短手动休息替换；重启保留截止时间。
- [ ] 默认休息只显示全屏遮罩，不跳到登录界面；有效限制期间遮罩没有秒数和关闭按钮，Alt+F4 不关闭。
- [ ] 休息中插拔显示器、负坐标副屏、混合 DPI 均完整覆盖；到期所有遮罩保留文本并显示关闭按钮。
- [ ] 服务中断超过 5 秒遮罩允许手动关闭；管理员长命令仍可解除；仅锁屏、仅遮罩、两者都选分别验收。

## 扩展休息与连续笔记

- [ ] 早睡解除设置为 06:30 后托盘显示“直到明天 6:30”，停用早睡计划仍可使用。
- [ ] `-h` 在控制台和重定向输出中可见；`-break 1`、`-break 120` 可用，0/121/小数拒绝。
- [ ] 托盘已运行时从另一个进程执行 `-break 30` 和 `-break-tomorrow 6` 能通过服务执行；已有承诺不能替换。
- [ ] 凌晨选择直到明天不会解释成今天；重启服务保留截止时间，夜间限制不会清掉较长的手动休息。
- [ ] 多屏笔记内容同步，输入时光标不因每秒刷新跳动；插拔显示器后文本保留。
- [ ] 到期不自动消失，解除任务管理器/锁屏后显示关闭按钮；明确关闭后再次打开文本仍在。
- [ ] 手动遮罩不计时、可关闭；有效强制遮罩不能通过手动打开绕过。
- [ ] 保存失败明确显示错误并保留窗口，便于复制内容；重启程序后能恢复最后保存的笔记。
- [ ] 遮罩仍显示时不累计下一轮工作时间；正常关闭后恢复计时。

- [ ] 深色遮罩在 1280×720、1920×1080、混合 DPI 下，提示位于左侧、按钮在其下方，右侧笔记卡片保持适当留白。
- [ ] 中文 CP936 与 UTF-8 控制台的 `-h` 显示中文；PowerShell 管道不乱码，执行后终端代码页不变。
