# LanSend（局域箱）

局域网内的轻量文件下载站、文件与文本上传中转站。

```sh
lansend [DIR]
```

`DIR` 是供其他设备浏览和下载的目录，默认当前目录；LanSend 不会创建或修改它。网页下载面板可进入其子目录，地址栏中的每一级目录均可点击跳转，符号链接不会暴露。上传和下载分别位于两个可切换的标签页中。

上传文件和通过“上传文本”提交的内容保存在独立的 `./lansend-data/` 中，默认不会创建该目录：第一次上传时创建文件，第一次上传文本时创建 `lansend-data/upload-text`。使用 `--upload-dir DIR` 可以更改它。

## 常用选项

- `--no-upload`：关闭上传及文本写入；可作为纯下载服务器使用。
- `--no-download`：关闭下载目录浏览。
- `--host ADDRESS --port PORT`：指定绑定地址和端口，默认 `0.0.0.0:8080`。
- `--token KEY`：启用入口令牌验证；未指定时默认不使用令牌。
- `--qrcode` 或 `--qr`：在终端中显示入口地址二维码；默认不显示。
- `-h` 或 `--help`：查看完整帮助。

启动时会枚举本机实际 IPv4 地址，例如 `http://10.64.0.10:8080/...`，而不是显示不可访问的 `http://[::]:8080`。使用 `--qrcode` 后，会在每个地址下输出紧凑、无外边框的二维码。指定 `--token KEY` 后，文字地址和二维码都使用带令牌的入口地址；直接打开网页会进入独立的令牌登录页面。

下载列表会根据文件开头的实际内容识别文本和图片，不依赖扩展名，因此 `.gitignore`、`go.mod`、`go.sum`、`LICENSE`、`Makefile` 等文件也能预览。文本预览会尝试 UTF-8、UTF-16 和 GB18030 编码；超过 1 MiB 时只传输并显示开头 1 MiB，避免浏览器卡顿。预览中可复制文本或下载完整原文件；识别为二进制的其他文件会直接下载。“上传文本”只负责将浏览器中的文字保存到服务器，不会把服务器内容同步回浏览器。
